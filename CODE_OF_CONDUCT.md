# Code of conduct

ConfigLab is committed to a professional, respectful, and technically focused
community.

Participants are expected to:

- discuss ideas and code without personal attacks;
- assume good faith while still giving direct technical feedback;
- avoid harassment, discrimination, threats, or deliberately disruptive
  behavior;
- respect privacy and do not publish another person's confidential information;
- follow the project owner's requests intended to keep project spaces
  constructive and on topic.

Unacceptable behavior may result in content removal or loss of participation
privileges. If a situation involves a security vulnerability or confidential
information, use the repository's private GitHub vulnerability-reporting channel rather than a
public issue when available.
