# Image-generation prompts

All three visuals were generated with the built-in image-generation tool and
saved into `assets/` for project use.

## `configlab-hero.png`

Use case: stylized-concept. A premium 16:9 cinematic technical illustration of
fragmented configuration sources converging into a precise layered resolver,
then flowing into one healthy application system. Deep navy background; cyan,
teal, violet, and restrained amber light; negative space for a title. No text,
logos, people, or watermarks.

## `runtime-lifecycle.png`

Use case: stylized-concept. A premium 16:9 visualization of complete runtime
source acquisition, deterministic resolution, validation, and transactional
replacement of an application's current configuration, including a failed
branch that leaves the current value unchanged. Deep navy, cyan/teal valid flow,
amber validation, muted red failure. No text, logos, people, or watermarks.

## `ecosystem-roadmap.png`

Use case: stylized-concept. A premium 16:9 modular ecosystem illustration with a
small complete crystalline core, an inner orbit of current capabilities, and a
more distant incomplete orbit of optional future integrations. Deep navy;
cyan/teal core, violet current modules, amber future modules. No text, logos,
people, puzzle pieces, or watermarks.
